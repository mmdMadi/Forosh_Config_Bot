# ربات فروش کانفیگ

یک ربات تلگرامی برای فروش و مدیریت اشتراک‌های VPN مبتنی بر 3X-UI. کاربران پلن‌ها را مشاهده می‌کنند، سفارش ثبت می‌کنند و رسید پرداخت را بارگذاری می‌کنند؛ مدیران سفارش‌ها را بررسی و حساب را مستقیم روی پنل ایجاد می‌کنند.

## امکانات

- **کاتالوگ پلن‌ها** — پلن‌ها در فایل `plans.json` تعریف شده و به‌صورت منوی اینلاین نمایش داده می‌شوند.
- **فرآیند سفارش** — کاربر پلن را انتخاب می‌کند، رسید پرداخت را بارگذاری می‌کند و سفارش در وضعیت «در انتظار» ثبت می‌شود.
- **تأیید مدیر** — مدیران سفارش را از داخل چت تأیید یا رد می‌کنند؛ بعد از تأیید، لینک اشتراک و کد QR برای کاربر ارسال می‌شود.
- **دستورات مدیریت پنل** — بررسی وضعیت سرور، اینباندها، کلاینت‌ها، نودها، هاست‌ها، لینک‌های اشتراک، کلاینت‌های آنلاین و وضعیت Xray.
- **سفارش آزمایشی** — مدیران می‌توانند حساب آزمایشی (بدون پرداخت) بسازند.
- **چندزبانه** — متن‌های رابط کاربری در `translations.json` نگهداری می‌شوند و کاربران با دستور `/lang` زبان را تغییر می‌دهند.
- **ذخیره‌سازی SQLite** — سفارش‌ها و تنظیمات کاربران در `bot.db` ذخیره می‌شوند.

## دستورات

| دستور | توضیح |
| --- | --- |
| `/start` | شروع ربات و نمایش منوی اصلی |
| `/help` | نمایش راهنما |
| `/buy` | مشاهده پلن‌های موجود |
| `/lang` | تغییر زبان |
| `/status` | وضعیت سرور (مدیر) |
| `/inbounds` | فهرست اینباندها (مدیر) |
| `/clients` | فهرست کلاینت‌ها (مدیر) |
| `/nodes` | فهرست نودها (مدیر) |
| `/hosts` | فهرست هاست‌ها (مدیر) |
| `/links` | دریافت همه لینک‌های اشتراک (مدیر) |
| `/online` | نمایش کلاینت‌های آنلاین (مدیر) |
| `/xray` | وضعیت Xray (مدیر) |
| `/settings` | تنظیمات ربات (مدیر) |

## پیش‌نیازها

- پایتون 3.10 یا بالاتر
- پنل [3X-UI](https://github.com/MHSanaei/3x-ui) با دسترسی API

## نصب

```bash
git clone https://github.com/mmdMadi/Forosh_Config_Bot.git
cd Forosh_Config_Bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## تنظیمات

فایل `.env.example` را به `.env` کپی کرده و مقادیر را پر کنید:

```bash
cp .env.example .env
```

| متغیر | توضیح |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | توکن از [@BotFather](https://t.me/BotFather) |
| `ADMIN_USER_IDS` | شناسه‌های تلگرامی مدیران (با کاما جدا شده) |
| `PANEL_URL` | آدرس پایه پنل 3X-UI (مثلاً `https://panel.example.com:2087`) |
| `PANEL_API_PATH` | مسیر API پنل (محرمانه نگه دارید) |
| `PANEL_USERNAME` / `PANEL_PASSWORD` | نام کاربری و رمز عبور پنل |
| `PANEL_API_TOKEN` | توکن API پنل (اختیاری) |
| `PANEL_SUB_PORT` | پورت لینک اشتراک (معمولاً `2096`) |

## ساختار پروژه

```
bot.py             منطق ربات تلگرامی و هندلرها
config.py          بارگذاری تنظیمات از محیط / فایل .env
db.py              ذخیره‌سازی SQLite (سفارش‌ها، تنظیمات کاربران)
panel_api.py       کلاینت API پنل 3X-UI
plans.json         تعریف پلن‌ها
translations.json  متن‌های رابط کاربری (چندزبانه)
tests/             مجموعه تست pytest
```
